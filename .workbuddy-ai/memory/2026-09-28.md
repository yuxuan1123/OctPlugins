#### 其他硬伤

- **`DisallowUnknownFields` 全仓无**（§7.5 MUST）：manifest 用 `json.Unmarshal` 解析，
  未知字段被静默忽略，作者写错字段名不会报错。
- **关闭路径跳过优雅阶段**（§10.3 MUST NOT）：仅 `recycle` 走 shutdown+grace；
  `StopPlugin` / `Restart` / `StopAll` 直接 `Process.Kill()`（plugin.go:523,533）。
- **状态被 9 处直接改写**（manager.go:554/622/673/684/779/809/889/913/1098），
  无 §12.2 要求的单一状态机 goroutine，onProcessExit 与 recycle 存在竞态面。
- **UI 绕过内核直读写文件**（§17.3 MUST NOT）：
  `ui/src/main.ts:212` 直读 `state/plugins/<id>/models.json`；
  `:227,238` 直写 `plugins/<id>/store/models.json`（还写进了插件包，违 §5.2）；
  `:250,305` 直读写 `state/hotkeys.json`。
- **Node SDK 只改道 `console.log`/`console.error`**（index.js:18-19），

- **SDK handler 内联同步执行**（`__init__.py:158-168`），业务阻塞 ping 应答，
